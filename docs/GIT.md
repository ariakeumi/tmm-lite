# Git Workflow

## Branches

Target the `devel` branch for all pull requests. Squash granular commits before merging.

## Commit Message Format

```
[Category] brief description of the change

- detailed point 1
- detailed point 2
```

**Categories:** Movies, TV shows, UI, Scraper, Performance, NFO, Renamer, etc.

Commit messages feed directly into the changelog — keep them clear and user-readable.
